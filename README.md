🌸 ROSE & BLOOM — Artisanal Café & Botanical Bakery🌿 About The ProjectROSE & BLOOM is an ultra-modern, glasshouse-inspired web application designed for a luxury botanical café and pink patisserie. It blends romantic floral aesthetic elements with robust interactive e-commerce and table reservation capabilities.Built as a lightweight single-page web app (SPA), it allows customers to explore floral espresso drinks, customize dairy & sweetness options, order baked pink patisserie items, reserve greenhouse seating, and send pre-filled orders directly to baristas via WhatsApp.📸 Visual Showcase for fresh daily bakes like Ruby Velvet Croissants, Rosewater Macaron Boxes, and Ruby Pistachio Éclairs.🛍️ Slide-Out Cart Drawer:Live subtotal, tax calculation (8.875%), and barista tipping
